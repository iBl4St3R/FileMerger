# FileMerger

Portable Windows tool (.NET 8, WPF) that merges many text files into one text file with a live preview.

- Build: `dotnet build FileMerger.sln -c Release`
- Test: `dotnet test tests/FileMerger.Tests -c Release`
- Artifacts: GitHub Actions → latest `build` run → `FileMerger` (needs .NET 8 Desktop Runtime) and `FileMerger-selfcontained`.

See `AGENTS.md` and `docs/` for details.
